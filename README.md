# Wanderlust - Travel Accommodation Booking Platform

## Overview
Wanderlust is a full-stack travel accommodation platform where users can explore, create, edit, and manage listings.

## Features
- User Authentication
- Login & Registration
- Session Management
- Create Listings
- Edit Listings
- Delete Listings
- Image Upload
- Responsive Design

### Frontend

### Backend
